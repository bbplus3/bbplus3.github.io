About

I spent 18+ years at Boeing — moving across quality engineering, business operations, and fabrication quality — before transitioning fully into data science and machine learning consulting. That arc shaped how I approach every technical problem: I know what a regulatory audit looks like, what an engineer actually needs to act on an anomaly flag, and what makes a dashboard useful to a director versus a floor supervisor. Most data scientists learn the domain after the fact; I built the ML on top of it.

The through-line in my work is deploying things that run. I've taken NLP models from research notebooks to Kubernetes-hosted production services with enterprise authentication. I've replaced brittle global time-series models with per-process baselines that actually captured manufacturing variation. I've shipped open-source Python libraries — with PyPI packages, public APIs, web apps, and browser extensions — because tooling that lives only on your laptop helps no one.

My technical foundation is broad by design. I hold an M.S. in Data Science and an M.S. in Technology Management alongside a B.S. in Statistics, and I work fluently across Python, R, SQL, PySpark, and the cloud and MLOps infrastructure that puts models in front of users. I'm comfortable with the full range from classical statistical methods — sampling theory, SARIMAX, hypothesis testing — to transformer-based NLP, FAISS nearest-neighbor search, and LLM API integration.

What I care about most is building systems that are honest about what they know, traceable to the decisions they inform, and maintainable by the teams that inherit them. That's not a soft commitment — it's the standard that 18+ years in aerospace quality instills, and I carry it into every project I take on.

Semantic Search & RAG App

Bible Verse Recommender

A deployed Streamlit application for biblical text analysis that combines semantic verse search with a retrieval-augmented generation flow: top retrieved verses are passed as context to the Anthropic Claude API, which generates a grounded reflection on the user's query theme. Image generation via the Pollinations.ai API is also integrated, composing verse text into a parameterized prompt with a hash-derived seed so identical prompts reproduce the same image. Error handling covers missing API keys, timeouts, and general failures with distinct user-facing messages.

"A hash-derived seed ensures identical prompts reproduce the same image while different prompts yield different ones — reproducibility applied to generative AI."

Time-Series Forecasting App

ts_ad — Utility Bill Forecasting & Anomaly Detection

A deployed forecasting application that models seasonal utility usage and projects future bills, built under real deployment constraints: an early Prophet-based build failed to compile within the free hosting environment's compute and memory limits, so I replaced it with a SARIMAX model that captured the same seasonality while running reliably within the platform's limits. Python Optimization Library

A Python library demonstrating optimization techniques for grid-planning-style problems, pairing classical optimization with an ML surrogate model and systematically benchmarking when each approach fits. The library is designed to make the comparison tractable and reproducible — exposing the conditions under which a surrogate outperforms classical methods rather than asserting one is always better.
